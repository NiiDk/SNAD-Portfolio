The Bridge Between Canva & Code

Samuel Nii Amu Darko · 20 Jun 2025

A lot of my design work happens in Canva: flyers, book covers, price lists and social media posts. A lot of my development work is CSS. The same decisions sit underneath both, and making them deliberately in one makes the other easier. Developers who understand typographic contrast, spacing and colour write CSS that is easier to maintain, because each decision is made once and reused instead of being made again for every element.

Decide what is read first

A flyer has a few seconds to be understood. Before choosing a font or a colour, it helps to decide the order in which things should be read. On the Queenzlook roll-up banner, the brand name comes first, then the list of services, then the location and phone number at the bottom. Size, weight, colour and position all serve that order.

An interface works the same way: the page title, then the main action, then the supporting detail. When everything on a screen is bold, large or brightly coloured, nothing stands out and the visitor has to work out the order alone.

Use a type scale, not a size per element

In a design tool it is easy to set each text box to whatever size looks right at the time. After a while a design has fifteen slightly different sizes and no clear relationship between them. A type scale fixes this by choosing a ratio and using only the sizes it produces. With a ratio of 1.25:

:root {
  --step-0: 1rem;      /* body text */
  --step-1: 1.25rem;
  --step-2: 1.563rem;
  --step-3: 1.953rem;
  --step-4: 2.441rem;  /* page titles */
}

In CSS, these become the only font sizes in the stylesheet. Headings can scale with the screen using clamp(), so a title is large on a laptop and still fits on a phone without a separate rule for every screen size.

Spacing from one unit

Canva's alignment guides make it easy to line things up by eye. In code, alignment holds up better when all spacing comes from one base unit, such as 4 or 8 pixels, and its multiples. Gaps between related items are small and gaps between sections are large, so the spacing itself tells the reader which items belong together.

A strict baseline grid, where every line of text sits on a shared horizontal grid, is hard to keep in CSS because images and mixed font sizes push lines off it. A consistent line height and a spacing scale built on the same unit give most of the benefit with far less effort.

Colour by role

A flyer usually works with a brand colour, one accent and a few neutrals. A website needs the same restraint, with colours defined by role rather than by name: background, text, muted text, lines, accent. On this site those roles are CSS variables, which is what lets the whole site switch between light and dark themes by changing a handful of values.

Roles also make contrast easier to manage. This site's accent is #FF5E4E. It is used as it is for lines, underlines and buttons, but small coral text on the light background uses a darker #C8372A, because the brighter shade does not have enough contrast to be read comfortably at small sizes.

Moving a design into code

When a design made in Canva becomes a web page, the first step is to write down the decisions already made: the font sizes, colours and spacing values the design uses. Those become variables, and the components come after. Starting with components and picking values along the way recreates the problem of fifteen slightly different sizes, this time in code.
